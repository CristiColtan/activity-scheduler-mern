# 📅 CCTask – Platformă Web pentru Managementul Activităților

**CCTask** este o platformă web modernă dezvoltată pentru gestionarea eficientă a sarcinilor în echipe, oferind funcționalități avansate de organizare, raportare, notificare și colaborare în timp real.

## 🔧 Tehnologii utilizate

- **Front-end:** React.js, Redux, Tailwind CSS  
- **Back-end:** Node.js, Express.js  
- **Baza de date:** MongoDB  
- **Autentificare & Storage:** Firebase (Google OAuth, Firebase Storage)  
- **Monitorizare & Loguri:** Winston + Elasticsearch + Kibana  
- **AI Assistant:** OpenAI API  

## ✨ Funcționalități principale

- Autentificare clasică și prin cont Google
- Interfață personalizată în funcție de rol: User, Team Manager, Administrator
- Management avansat al sarcinilor și subtask-urilor
- Sistem de notificări în timp real
- Asistent virtual bazat pe inteligență artificială
- Generare de statistici și rapoarte dinamice
- Sistem de logare și trasabilitate a evenimentelor
